Remote access

Install the Cloudflare Tunnel connector without SSH. Privileged setup stays behind the normal local KEMS address and is blocked when the request arrives through a proxy or tunnel.

Cloudflare Tunnel connector

KEMS accepts only the connector token from the Cloudflare command. It never executes pasted shell commands.

Checking the Pi connector…

Paste the command Cloudflare shows for your tunnel. KEMS extracts only the token, stores it root-only, installs the current cloudflared package, and starts a dedicated connector service.
