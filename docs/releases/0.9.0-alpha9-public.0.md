# KEMS Public Web 0.9.0-alpha9-public.0

Alpha9 Public.0 establishes `kems.uk` as an independently versioned Public Web product.

## Preserved behaviour

- Preserves the current public home, delayed demo, comparison, login, privacy and error-page behaviour.
- Preserves the minimum seven-day delayed public demo boundary and the existing credential/control exclusions.
- Does not receive Home Assistant credentials, live control APIs or precise live household power.

## Independent release/deployment identity

- Version source: `public-site/version.json`.
- Release tag family: `public-v*`.
- Public release publisher: `.github/workflows/release-public.yml`.
- IONOS deployment is triggered by Public Web/brand/deployment-source changes, not by a Pi Web `package.json` version bump.

Pi Web remains a separate product at `0.9.0-alpha9-web.0`.
