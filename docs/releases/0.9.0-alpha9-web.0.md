# KEMS Pi Web 0.9.0-alpha9-web.0

Alpha9 Web.0 is the coordinated Pi Web parity baseline after the Alpha8 cleanup cycle.

## Preserved behaviour

- Preserves the proven `0.8.0-alpha8-web.11` Pi/property application behaviour.
- Keeps `/kems.html` as the canonical KEMS property route and `/agile.html` as compatibility redirect only.
- Keeps one controlled KEMS renderer, the canonical bill contract, current/tomorrow Agile slot evidence and the read-only control/commissioning projection.
- Keeps Pi update and maintenance controls local-only and does not add Home Assistant control service calls.

## Release identity

Pi Web is independently versioned as `0.9.0-alpha9-web.0`.

Public Web is no longer treated as the Pi Web release. It has its own `0.9.0-alpha9-public.0` version source, tag and publisher even while the two products remain in the same repository.
