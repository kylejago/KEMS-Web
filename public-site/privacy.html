Public website privacy

The public site does not need access to your live home.

This static kems.uk website is deliberately separated from KEMS property appliances and Home Assistant.

No Home Assistant credentialsThe public site does not request, store or transmit Home Assistant URLs, access tokens or KEMS property credentials.
Only delayed demo evidenceThe public demo reads sanitised daily totals delayed by at least seven days from a dedicated hostname. Precise live power, entity IDs, device identifiers and control surfaces are excluded.
No KEMS password databasePrivate property sign-in is handled by Cloudflare Access. The public website does not store a separate username/password database.
No control pathThe public site cannot call Home Assistant services or issue commands to an inverter, charger, ESP32 panel or other property device.

Authenticated property access is a separate Cloudflare boundary leading to a read-only Pi dashboard through an outbound property tunnel. Local Pi management and Home Assistant control remain LAN-only. Hosting and security providers may retain ordinary delivery/security logs. KEMS itself adds no advertising trackers in this release.
