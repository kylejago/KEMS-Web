Private property access

Sign in once. Open only the KEMS properties you are allowed to see.

KEMS uses Cloudflare Access as the authentication boundary. kems.uk does not store a separate KEMS password database, Home Assistant credentials or property access tokens.

Sign in to KEMSView delayed demo

After authentication, the KEMS property launcher shows only the Access applications your account is permitted to open. Each property remains behind its own outbound Cloudflare Tunnel.

Secure property accessCloudflare identity → KEMS property launcher → authorised property → outbound tunnel → read-only Pi dashboard

Local Pi maintenance, Remote Access setup, Home Assistant and hardware-control endpoints remain unavailable through the public property route.
