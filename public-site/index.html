Flagship strategy

Observe and learn

Start with the home you actually have.

KEMS records real demand and tariff behaviour instead of starting with an idealised model. That evidence becomes the baseline used by every later comparison.

Prove before control

KEMS is built around a deliberate safety boundary.

Home Assistant remains private. Live property data and credentials stay with the property. The public website receives only deliberately sanitised delayed evidence, while authenticated property access is handled through Cloudflare Access and outbound tunnels.
