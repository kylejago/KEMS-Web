Prove before control

KEMS is built around a deliberate safety boundary.

On kems.uk, Home Assistant remains private. Live property data and credentials stay with the property. The public website receives only deliberately sanitised delayed evidence, while authenticated property access is handled through Cloudflare Access and outbound tunnels.
